🚦 Jogo de Atravessar a Rua do Pocoyo

Um jogo inspirado no Pocoyo, no qual o jogador precisa ajudar o personagem a atravessar a rua com segurança, desviando dos carros.

📌 Sobre o projeto

O objetivo do jogo é controlar a Nina e ajudá-la a chegar ao outro lado da rua sem ser atingida pelos veículos.

O jogador precisa prestar atenção no movimento dos carros e escolher o momento certo para atravessar.

🎮 Como jogar
Use as teclas de movimentação para controlar a Nina;
Atravesse a rua evitando os carros;
Não encoste nos veículos;
Chegue ao outro lado para vencer!
🚀 Funcionalidades
Movimentação do personagem;
Carros se movimentando pela pista;
Detecção de colisões;
Sistema de vitória e derrota;
Controles pelo teclado;

🎯 Objetivo

O projeto foi desenvolvido para praticar lógica de programação, movimentação de personagens, colisões, eventos de teclado e desenvolvimento de jogos com Python.
